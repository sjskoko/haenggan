# 행간

**하루를 따라 마음을 읽다**

목소리나 글로 하루를 남기고 한 주의 감정과 상황 변화를 돌아보는 일기입니다. 화면은 오늘 · 기록 · 한 주로 구성합니다.

## 0.2.0-preview

녹음 중단 복구와 원문을 보존하는 AI 정제 및 화면 정렬을 개선했습니다. [변경 사항과 검증 범위](docs/RELEASE-0.2.0.md)를 확인해 주세요. 이번 CI APK는 새 설치 검토용이며 기존 0.1.1에 덮어쓰는 호환 업데이트가 아닙니다. 기존 앱을 삭제하지 마세요.

## Android 앱

`mobile/android`는 휴대폰 안에서 실행되는 오픈소스 앱입니다. Android 13 이상을 대상으로 합니다.

- **내 ChatGPT 구독 연결**: 공식 Sign in with ChatGPT OAuth 흐름을 사용합니다. 사용자가 자신의 계정과 워크스페이스를 선택하고 구독 사용을 승인합니다. 별도의 OpenAI API 키나 개발자 공용 결제 계정을 사용하지 않습니다.
- **개인 보관**: 일기와 토큰은 Android Keystore 키로 암호화한 앱 전용 저장소에 보관합니다. 각 계정 등록과 기기 전용 일기장을 분리합니다. 계정 간 또는 기기 간 자동 동기화는 없습니다.
- **최소 화면**: 오늘 기록 · 검색과 수정 · 주간 회고 · 다음 주에 남길 말. 원문을 먼저 저장하고 AI 정리는 별도로 실패할 수 있습니다.
- **기기 알림**: 한국시간 매일 23:30. 소리와 진동이 있는 중요도 높은 알림이며 누르면 작성 화면을 엽니다. 알림 권한과 정시 알림 권한은 사용자가 허용합니다. 정시 권한이 없으면 절전 상태에 따라 지연될 수 있습니다.
- **음성 입력**: Android 음성 인식으로 글을 남깁니다. 기기 내 인식을 우선 사용합니다. 기기 내 인식이 불가능하면 외부 음성 인식 서비스 사용에 동의한 뒤 실행합니다. 이 버전은 원음 파일을 보관하지 않습니다.
- **백업**: 선택한 계정의 일기만 JSON으로 내보냅니다. OAuth 토큰은 백업에 포함하지 않습니다. 자동 백업과 앱 재설치 복원은 지원하지 않습니다.

### 현재 검증 범위

`0.1.1-preview`는 브라우저 승인 중 앱이 백그라운드로 이동할 때 응답 대기가 멈출 수 있는 구조를 보완합니다. 로그인 중에만 짧은 포그라운드 서비스를 실행하고 완료·실패·취소 시 종료합니다. 승인 응답은 150초까지 기다리며 서비스는 170초 안에 종료합니다. HTTP 요청 헤더를 끝까지 읽고 브라우저의 빈 사전 연결을 무시합니다. 실패 단계 코드와 다른 브라우저로 다시 연결하는 동작을 제공합니다. 승인 화면의 멈춤이 실제 기기에서 해결되는지는 추가 확인이 필요합니다.

이 버전은 **미리보기**입니다. 실제 휴대폰에서의 ChatGPT 로그인 동의 · 구독 요청 · 백그라운드 알림은 기기별 확인이 필요합니다. 기존 ChatGPT 대화나 기억을 읽는 기능은 없습니다. 계정의 요금제와 구독 사용 권한은 OpenAI에서 판단하며 모든 유료 요금제를 지원한다고 가정하지 않습니다.

공식 구독 연결은 현재 지원되는 Responses 텍스트 요청에 사용합니다. 음성 전사 API · ChatGPT 음성 모드 · 개발자 API의 모든 기능을 포함하는 연결이 아닙니다. 서버가 반환하는 해당 계정의 모델 목록을 사용합니다. 사용 한도에 닿으면 안내하고 중단하며 유료 API로 자동 전환하지 않습니다.

### 빌드

JDK 17 · Android SDK 36이 필요합니다.

```sh
cd mobile/android
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

결과는 `app/build/outputs/apk/debug/app-debug.apk`입니다. 디버그 APK는 설치 검증용입니다. 정식 배포용 APK에는 소유자가 관리하는 지속적인 서명 키가 필요합니다. CI는 테스트 후 미리보기 APK를 빌드 아티팩트로 남깁니다.

### 계정 연결 설계

1. 설치별 안정적인 호스트 ID와 새 PKCE · state · nonce를 생성합니다.
2. 기기의 루프백 콜백을 연 뒤 기본 브라우저에서 공식 OpenAI 승인 화면을 엽니다.
3. 반환된 클라이언트 ID를 계정별로 저장하고 코드와 PKCE를 교환합니다.
4. ID 토큰의 서명 · 발급자 · 대상 · 만료 · nonce와 재연결 시 기존 계정을 검증합니다.
5. 실제 승인된 구독 scope가 있을 때만 AI 기능을 활성화합니다.
6. 토큰 갱신을 직렬화하고 교체 토큰을 함께 저장합니다. 연결 해제는 원격 폐기를 시도한 뒤 기기의 토큰을 지웁니다.

토큰을 WebView · 브라우저 저장소 · 로그 · GitHub에 전달하지 않습니다. 원격 웹페이지를 WebView에 로드하지 않고 패키지 안의 화면만 표시합니다. 사용자 글은 HTML로 실행하지 않습니다. 현재 서명 검증은 RS256을 지원하며 다른 알고리즘은 허용하지 않습니다.

## 웹 일기장

루트는 Vinext + React + Cloudflare D1/R2로 만든 별도의 웹 일기장입니다. 웹 로그인은 Sites가 제공하는 계정 식별을 사용합니다. **웹 로그인 자체로 ChatGPT 구독을 사용할 수는 없습니다.** 현재 사용자 요청에 따라 API 키를 발급하거나 등록하지 않았습니다. 웹 AI와 예약 푸시는 기본 비활성입니다. Android 앱의 일기와 웹 일기는 동기화되지 않습니다.

```sh
pnpm install
pnpm dev
pnpm build
```

Sites 배포는 소유자가 발급한 프로젝트 ID와 저장소 바인딩이 필요합니다. `app/chatgpt-auth.ts`는 신뢰할 수 있는 Sites 게이트웨이가 주입한 인증 헤더를 사용하므로 **인증 게이트웨이 없이 그대로 공개 서버에 올리지 마세요.** 일반 호스팅으로 옮길 때는 별도의 검증된 세션 인증을 구현해야 합니다. GitHub Pages는 정적 호스팅이므로 이 웹 서버의 대체 배포 대상이 아닙니다.

`PRIVATE_SCHEDULE_ENABLED`는 owner-private Sites에서만 사용할 수 있는 예약 실행 경로입니다. 다중 사용자 공개 호스팅에서 켜지 말고 별도의 서버 인증을 구현하세요. 환경변수와 사용자 데이터는 소스에 넣지 않습니다.

## 검증

- Android: 계정 서명 검증과 스트림 완료·실패 처리 단위 테스트
- 웹: TypeScript 검사와 프로덕션 빌드
- `tests/api-smoke.mjs`: 개발 환경의 인증·사용자 간 격리·수정 충돌·CSRF·내보내기 격리 검증. 신뢰 게이트웨이 헤더를 직접 주입하는 **로컬 개발 전용** 테스트입니다.
- 실제 휴대폰 승인·알림 확인은 `docs/DEVICE_CHECKS.md`를 따릅니다.
