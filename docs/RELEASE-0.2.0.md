# 0.2.0-preview — 2026-11-10

## 변경 사항

- Android 화면의 좌우 기준선과 버튼 여백을 통일했습니다. 장식용 마이크 그림자와 반복적인 감성 문구를 줄였습니다. 작은 화면에 맞춰 버튼 줄바꿈을 허용했습니다.
- 음성 입력 경과 시간과 상태를 표시합니다. 잠시 멈춘 뒤 이어 말할 수 있습니다. 확보한 임시 전사문은 신규 일기의 암호화 초안에 보관하며 인식 중단 시 편집창으로 복구합니다. 원음은 저장하지 않습니다.
- 저장한 원문에서 별도로 AI 정제본을 생성합니다. 원문과 비교한 뒤 직접 수정하고 채택할 수 있습니다. 실패하면 원문을 유지하며 기록에서 다시 시도합니다. 기존 짧은 요약은 별도 동작으로 남겼습니다.
- 한국시간 새벽 4시 전에는 새 일기 날짜를 전날로 제안합니다. 날짜는 직접 바꿀 수 있습니다.
- 오래된 음성 인식 콜백이 새 인식 세션에 섞이지 않도록 세션을 구분합니다.

## 설치와 서명 주의

기존 0.1.1-preview를 만든 작업 환경과 서명 키를 이번 실행에서 찾을 수 없었습니다. 이 버전의 CI 디버그 APK는 새 설치 검토용입니다. **기존 앱에 덮어쓰는 호환 업데이트가 아닙니다. 기존 앱을 삭제하지 마세요.** 기존 데이터 보존 업데이트를 배포하려면 이전 서명 키를 확보한 뒤 동일 키로 다시 서명해야 합니다. 새 기기나 기록이 없는 테스트 환경에서만 설치를 확인해 주세요. 서명 키는 저장소에 포함하지 않습니다.

## 검증 범위

JavaScript 문법 검사와 모의 네이티브 브리지를 통한 UI 동작 검사를 수행합니다. `tests/android-ui.cjs`는 jsdom이 필요합니다. 임시 전사 복구와 이어 말하기 및 초안 저장과 전날 날짜 선택과 정제본 수정·원문 보존·AI 실패 복구를 확인합니다. 이는 실제 마이크나 실제 AI 요청 검증을 대체하지 않습니다.

Android JVM 테스트와 Gradle APK 빌드는 GitHub Actions에서 실행합니다. 실제 실행 결과는 해당 커밋의 Actions 상태를 확인해야 합니다. 로컬 Gradle 실행은 네트워크 제한에 막혔습니다. 실제 휴대폰 로그인·마이크 권한·전화 수신·알림·큰 글꼴·키보드 레이아웃 검증은 미완료입니다. 로컬 브라우저 렌더링은 실행 환경의 소켓 제한에 막혔습니다.

## 남은 항목

계정 간 기록 이동과 백업 가져오기·삭제 취소 및 알림 시간·요일·미루기 설정과 앱 잠금은 아직 구현하지 않았습니다. 기존 일기 수정 중의 별도 초안 복원과 프로세스 강제 종료 시 마지막 임시 전사 완전 복구도 후속 과제입니다. 주간 회고의 상황·감정·날짜 근거는 기존 기능을 유지합니다. 지난주 마음가짐의 다음 주 연결은 아직 구현하지 않았습니다. 0.1.1의 로그인 수정이 실제 기기에서 문제를 해결했는지는 확인되지 않았습니다.
