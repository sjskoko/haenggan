# 휴대폰 검증 항목

실제 사용자의 구독 승인과 기기 권한을 대신 완료했다고 표시하지 않습니다.

- Android 13 이상에서 설치하고 글 작성·재실행·수정·삭제·백업을 확인한다.
- 서로 다른 두 계정을 연결한 뒤 기록과 초안이 섞이지 않는지 확인한다.
- 브라우저에서 연결을 거절했을 때 기존 계정이 유지되는지 확인한다.
- 브라우저 승인 후 앱으로 돌아와 연결된 계정과 구독 사용 안내가 표시되는지 확인한다.
- 0.1.1: 연결 중 알림이 표시되고 브라우저에서 30초 이상 기다린 뒤 승인해도 응답을 받는지 확인한다. 알림 권한을 거절한 기기에서도 확인한다.
- 0.1.1: 승인 거절·연결 취소·150초 대기 만료 후 로그인 서비스가 종료되는지 확인한다. 실패 화면의 다른 브라우저 선택으로 새 연결을 시작한다.
- 0.1.1: 삼성 인터넷과 Chrome에서 각각 승인·앱 복귀를 확인한다. 실제 기기 검증 전에는 특정 브라우저의 문제가 해결됐다고 표시하지 않는다.
- 한 번의 일기 정리와 주간 회고를 요청하고 실제 구독 사용량을 확인한다.
- 권한 없음·한도 도달·네트워크 끊김에서 원문이 남고 추가 결제가 일어나지 않는지 확인한다.
- 연결 해제 후 AI가 멈추고 재연결에 승인이 필요한지 확인한다.
- 마이크 거절·한국어 오프라인 모델 없음·음성 인식 종료를 확인한다.
- 알림 권한을 켜고 테스트 알림을 누르면 작성 화면이 열리는지 확인한다.
- 앱 종료와 기기 재부팅 후 밤 23:30 알림을 확인한다. 정시 권한 미허용 시 지연 안내가 보이는지 확인한다.
- 오늘 일기를 이미 저장한 경우 해당 밤의 알림이 생략되는지 확인한다.
- 잠금 화면 알림에 일기 내용이 나오지 않는지 확인한다.

현재 구현의 범위: Android 설치형 미리보기. iOS 앱·앱스토어 배포·자동 동기화·백업 복원·원음 보관은 포함하지 않는다.
